# Правила роботи над GFX

Під час перевірки або зміни GFX-плагінів обов’язково прочитай і виконуй [GFX_PORTING_RULES.md](GFX_PORTING_RULES.md).

Основна вимога користувача: переносити й адаптувати оригінальні алгоритми C++ Angelica до Unity для всіх підтримуваних ефектів. Не підганяти реалізацію під назву, шлях або вигляд одного GFX. Візуальна схожість сама по собі не доводить правильність алгоритму.

Наявні незакомічені зміни зберігати. Оригінальні вихідники Angelica та вихідні ігрові ассети не змінювати для досягнення збігу.
